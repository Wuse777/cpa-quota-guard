# CPA Quota Guard 0.3.0

首次安装以观察模式运行，默认关闭自动兑换，新增账号默认不参加；升级保留已有策略与执行记录。请特别检查旧策略的 `include_new_accounts` 兼容行为：缺省仍为 `true`，避免升级擅自改变既有自动化。

额度与卡片任务独立调度，有限并发、失败退避并保留最后成功额度；同一账号兑换串行化。页面将实时概览和策略草稿分开，增加账号筛选、异常聚合、保存冻结和冲突草稿保护。可选私有 Webhook 通知默认关闭。

安装器按调度能力预检，允许有精确 SHA256 声明的管理/SSO 插件共存；面板扩展须精确区块声明，同时继续校验原始 CPAMC HTML。`--doctor` 可独立诊断，构建 manifest 绑定版本、commit、时间与 `.so` 摘要。安装失败后恢复文件，并验证原服务 active 和原版本 API。

已验证目标仍为 CPA 8.0.35 / CPAMC 1.26.5、Linux amd64/glibc、C ABI 1 / schema 6。PR 和标签发布门禁包含固定版本+SHA256 的真实 CPA 隔离集成、process/systemd 组合安装回滚、Chromium 界面回归及真实 CPAMC 会话桥接。测试仅使用虚构账号。

升级须运行新版安装器，不能只替换 `.so`。既有其他插件和面板扩展声明、回滚与通知配置见 [安装](../INSTALLATION.md)、[配置](../CONFIGURATION.md)、[兼容性](../COMPATIBILITY.md) 和 [测试](../TESTING.md)。
