# CPA Quota Guard 0.2.1

首个公开发布，包含按账号/窗口的额度保留、Codex 临期重置卡自动使用和 CPAMC 会话集成。

## 兼容性

- CLIProxyAPI 8.0.35，C ABI 1 / JSON schema 6。
- CPAMC 1.26.5，原始 HTML SHA256 必须符合兼容性文档。
- Linux amd64 / glibc；构建环境 Ubuntu 24.04、Go 1.27.3。

## 界面

字体、布局、控件和动效对齐原生 CPAMC，支持纯白、羊毛纸与暗色主题。自动刷新保护表单草稿，标签页可用键盘切换，窄屏布局采用纵向排列。

## 首次安装须知

额度保护默认只观察；自动使用重置卡默认开启，提前 6 小时，独立于观察/执行模式。希望第一次启动前关闭自动兑换时，按安装文档使用 `policy.safe-start.example.json`。上游不能指定消耗哪张卡，插件不保证额度绝对下限或卡片必定兑换成功。

下载归档及 SHA256SUMS，先校验再解压。安装器会备份配置、插件和面板并验证注册，失败自动回滚。原有策略及执行记录升级时保留。不要在运行中删除兑换 journal。

## 验证范围

Go race / vet、Node 会话测试、Python 安装/桥接单元测试、22 项隔离 CPA 及 3 项隔离 systemd 安装/回滚检查。上游卡片兑换的失败/重试/去重通过本地模拟服务验证，未为发布验证而提前消费真实卡。
