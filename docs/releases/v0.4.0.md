# 0.4.0

新增 Codex 额度刷新后的自动激活。自然到期或使用重置卡恢复后，以极短模型请求及时启动五小时/周额度计时。

- 根据真实账号与窗口周期持久化去重，支持单周窗口，合并同时刷新的窗口。
- 从账号可用目录自动选模或在界面指定模型，使用最低支持思考档。
- 单次本机管理转发，固定账号；尊重现有保护阈值，未知或不确定结果不会盲目补发。
- 独立开关、账号/来源/窗口设置、模型与 token 记录，区分调用成功和计时确认。
- 升级保留原策略，新增自动激活默认关闭。

开发验证使用虚构账号和本地上游，不消耗真实重置卡。安装和使用说明见 `docs/INSTALLATION.md` 与 `docs/CONFIGURATION.md`。本文件是源码版本说明，不代表已公开发布 GitHub Release。
