# 兼容性

当前适配与验证基于 CLIProxyAPI **8.0.35** 和 CPAMC **1.26.5**。插件使用 C ABI 1、JSON schema 6，依赖宿主的认证文件读取、代理请求和配额冷却回调。

CPAMC 会话桥接使用该构建现有的认证状态与 API 客户端，因此同时绑定面板构建内容。已接受的原始 `management.html` SHA256：

```text
57558cd023475674634a114824b014d3e5ac161f6f3791e3d86b6adab962a700
```

`cpamc_bridge.py` 在校验前移除旧版本的同名桥接，因此重复安装和升级是幂等的。桥接不完整或原始 HTML 哈希不匹配时，安装器修改前失败。版本号相同但内容不同的面板不自动兼容。

安装器将 CPAMC 自动更新关闭，避免面板更新覆盖桥接或改变依赖的模块。后续升级需重新核对认证存储、API 客户端、iframe 挂载和主题变量，完成会话限制及浏览器测试后再加入新哈希；不要单纯把未知哈希加入白名单。

目前的预编译目标为 Linux amd64 / glibc，构建与验收使用 Ubuntu 24.04、Go 1.27.3。ARM64、musl/Alpine、其他系统及 CPA / CPAMC 版本未验证。支持编译目标不等于已完成宿主兼容性验证。

仓库不包含上游 CPA 二进制或 CPAMC HTML；请从各自官方项目取得并自行校验。第三方来源和许可见仓库 `NOTICE`。
